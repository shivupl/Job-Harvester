# jobwatch Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Python package that harvests startup ATS slugs from Hacker News, verifies them against Greenhouse/Lever/Ashby, and three times per weekday scores new postings with Claude and files a GitHub issue digest.

**Architecture:** One package `jobwatch/` with one module per pipeline stage (http, harvest, ats adapters, store, prefilter, score, digest, run) and a tiny CLI. All thresholds live in `jobwatch/profile.py`. State is one SQLite file committed to git. Delivery is a GitHub Actions workflow with three cron slots serialized by a concurrency group.

**Tech Stack:** Python 3.9+ syntax (laptop is 3.9, Actions runs 3.12), `httpx` (async HTTP), `anthropic` SDK 0.125+ (`messages.create` with `output_config` structured outputs), stdlib `sqlite3`, `pytest` + `pytest-asyncio` (auto mode).

**Spec:** `docs/superpowers/specs/2026-09-04-jobwatch-design.md`

## Global Constraints

- Python syntax must run on 3.9: every module starts with `from __future__ import annotations`; use `Optional[X]` not `X | None` at runtime; no `match` statements.
- No config files, no env vars other than `ANTHROPIC_API_KEY` (loaded from `.env` by the CLI). Every threshold is in `PROFILE`.
- No live network in tests. HTTP is mocked with `httpx.MockTransport`; the Anthropic client is replaced with a fake.
- Public JSON GET endpoints only. No HTML scraping.
- Rate limiter is keyed by hostname, shared across all workers, default 3 req/s per host.
- Harvest extracts facts; it never guesses slugs.
- Every dropped posting stores title, company, and reason.
- `VACUUM` at most once per calendar month.
- Digest files are `digests/YYYY-MM-DD-<slot>.md` in America/Los_Angeles and never overwritten.
- Model is `claude-haiku-4-5`, no date suffix.
- Commit after every task with the trailer lines shown in Task 1.
- Run tests with `.venv/bin/python -m pytest` (the venv already exists at `.venv/` with deps installed). Use `.venv/bin/python` for every command in this plan.

```python
from __future__ import annotations

import html
import re
from datetime import datetime, timezone
from typing import Optional

_TAG = re.compile(r"<[^>]+>")
_BLOCK_END = re.compile(r"</(?:p|div|li|ul|ol|h[1-6]|br|tr)>|<br\s*/?>", re.I)


def strip_tags(s: str) -> str:
    """Strip HTML tags, unescape entities, collapse whitespace. Block ends become newlines."""
    s = _BLOCK_END.sub("\n", s)
    s = _TAG.sub(" ", s)
    s = html.unescape(s)
    s = re.sub(r"[ \t\r\f\v]+", " ", s)
    s = re.sub(r" *\n *", "\n", s)
    s = re.sub(r"\n{2,}", "\n", s)
    return s.strip()


def to_utc_iso(value) -> Optional[str]:
    """Normalize ISO strings (with offset or Z) or epoch milliseconds to ISO UTC, second precision."""
    if value is None or value == "":
        return None
    try:
        if isinstance(value, (int, float)):
            dt = datetime.fromtimestamp(value / 1000, tz=timezone.utc)
        else:
            s = str(value).strip().replace("Z", "+00:00")
            dt = datetime.fromisoformat(s)
            if dt.tzinfo is None:
                dt = dt.replace(tzinfo=timezone.utc)
    except (ValueError, OverflowError, OSError):
        return None
    return dt.astimezone(timezone.utc).replace(microsecond=0).isoformat()


def now_utc() -> datetime:
    return datetime.now(timezone.utc)
```

`jobwatch/http.py`:

```python
from __future__ import annotations

import asyncio
import time
from typing import Any, Optional
from urllib.parse import urlsplit

import httpx

USER_AGENT = "jobwatch/0.1 (personal job digest; polite, rate-limited)"
RETRY_STATUSES = {429, 500, 502, 503, 504}


class HostLimiter:
    """Spaces requests to each hostname at most `rps` per second.

    One reservation ledger per host, shared by every caller. Callers reserve
    the next free slot under a lock, then sleep until it arrives, so N
    concurrent workers never exceed the per-host rate.
    """

    def __init__(self, rps: float):
        self.interval = 1.0 / rps
        self._next: dict[str, float] = {}
        self._lock = asyncio.Lock()

    async def wait(self, host: str) -> None:
        async with self._lock:
            now = time.monotonic()
            slot = max(now, self._next.get(host, now))
            self._next[host] = slot + self.interval
        delay = slot - time.monotonic()
        if delay > 0:
            await asyncio.sleep(delay)


class Http:
    def __init__(
        self,
        rps: float = 3.0,
        workers: int = 30,
        retries: int = 3,
        client: Optional[httpx.AsyncClient] = None,
        timeout: float = 30.0,
    ):
        self.limiter = HostLimiter(rps)
        self.sem = asyncio.Semaphore(workers)
        self.retries = retries
        self.base_delay = 2.0
        self.client = client or httpx.AsyncClient(
            timeout=timeout,
            headers={"User-Agent": USER_AGENT},
            follow_redirects=False,
        )

    async def aclose(self) -> None:
        await self.client.aclose()

    def _retry_delay(self, resp: Optional[httpx.Response], attempt: int) -> float:
        if resp is not None:
            ra = resp.headers.get("retry-after")
            if ra and ra.isdigit():
                return float(ra)
        return self.base_delay * (2 ** attempt)

    async def request(self, method: str, url: str, **kw) -> httpx.Response:
        host = urlsplit(url).hostname or url
        resp: Optional[httpx.Response] = None
        last_exc: Optional[Exception] = None
        for attempt in range(self.retries):
            async with self.sem:
                await self.limiter.wait(host)
                try:
                    resp = await self.client.request(method, url, **kw)
                    last_exc = None
                except httpx.TransportError as e:
                    resp, last_exc = None, e
            if resp is not None and resp.status_code not in RETRY_STATUSES:
                return resp
            if attempt < self.retries - 1:
                await asyncio.sleep(self._retry_delay(resp, attempt))
        if resp is not None:
            return resp
        assert last_exc is not None
        raise last_exc

    async def get(self, url: str, **kw) -> httpx.Response:
        return await self.request("GET", url, **kw)

    async def head(self, url: str) -> httpx.Response:
        return await self.request("HEAD", url)

    async def get_json(self, url: str) -> tuple[int, Any]:
        resp = await self.get(url)
        if resp.status_code != 200:
            return resp.status_code, None
        try:
            return 200, resp.json()
        except ValueError:
            return 200, None
```

```python
from __future__ import annotations

import asyncio
import html
import re
from pathlib import Path
from typing import Optional

from .http import Http

ALGOLIA = "https://hn.algolia.com/api/v1"
SEARCH_URL = (
    ALGOLIA + "/search_by_date?query=%22Ask%20HN%3A%20Who%20is%20hiring%3F%22"
    "&tags=story,author_whoishiring&hitsPerPage=200&page={page}"
)
THREAD_TITLE = "Ask HN: Who is hiring?"

GH_PATTERNS = [
    re.compile(r"boards\.greenhouse\.io/embed/job_board\?for=([A-Za-z0-9_-]+)"),
    re.compile(r"(?:boards|job-boards)\.(?:eu\.)?greenhouse\.io/([A-Za-z0-9_-]+)"),
]
OTHER_PATTERNS = [
    re.compile(r"jobs\.(?:eu\.)?lever\.co/([A-Za-z0-9_-]+)"),
    re.compile(r"jobs\.ashbyhq\.com/([A-Za-z0-9_.-]+)"),
]
SHORT_PATTERN = re.compile(r"grnh\.se/([A-Za-z0-9]+)")

BLOCKLIST = {
    "embed", "api", "v0", "v1", "static", "assets", "search", "login",
    "about", "privacy", "terms", "jobs", "careers", "job_board",
}
FILE_EXTS = {
    "png", "jpg", "jpeg", "gif", "svg", "webp", "ico", "css", "js",
    "html", "htm", "json", "xml", "txt", "pdf",
}


def is_valid_slug(slug: str) -> bool:
    low = slug.lower()
    if len(low) < 2 or low in BLOCKLIST:
        return False
    if "." in low and low.rsplit(".", 1)[1] in FILE_EXTS:
        return False
    return True


def extract_slugs(raw: str) -> set[str]:
    """Run every ATS pattern over the unescaped raw body. Never walks the tree."""
    text = html.unescape(raw)
    found: set[str] = set()
    for pat in GH_PATTERNS + OTHER_PATTERNS:
        found.update(pat.findall(text))
    return {s for s in found if is_valid_slug(s)}


def extract_short_codes(raw: str) -> set[str]:
    return set(SHORT_PATTERN.findall(html.unescape(raw)))


async def resolve_short(http: Http, code: str) -> Optional[str]:
    """HEAD without following; fall back to GET when the shortener won't redirect a HEAD.

    Only a Location on a Greenhouse host yields a slug. Anything else (a
    company's own careers page) is discarded: harvest never guesses.
    """
    url = f"https://grnh.se/{code}"
    resp = await http.head(url)
    if not (300 <= resp.status_code < 400):
        resp = await http.get(url)
    loc = resp.headers.get("location", "")
    for pat in GH_PATTERNS:
        m = pat.search(loc)
        if m and is_valid_slug(m.group(1)):
            return m.group(1)
    return None


async def list_threads(http: Http, months: Optional[int]) -> list[dict]:
    hits: list[dict] = []
    page = 0
    while True:
        status, data = await http.get_json(SEARCH_URL.format(page=page))
        if status != 200 or not data or not data.get("hits"):
            break
        hits.extend(h for h in data["hits"] if (h.get("title") or "").startswith(THREAD_TITLE))
        page += 1
        if page >= int(data.get("nbPages", 1)):
            break
    hits.sort(key=lambda h: h.get("created_at", ""), reverse=True)
    return hits[:months] if months else hits


async def harvest_thread(http: Http, thread_id: str) -> tuple[set[str], set[str]]:
    resp = await http.get(f"{ALGOLIA}/items/{thread_id}")
    if resp.status_code != 200:
        return set(), set()
    return extract_slugs(resp.text), extract_short_codes(resp.text)


def merge_seeds(path: Path, slugs: set[str]) -> tuple[list[str], int]:
    existing = set(path.read_text().split()) if path.exists() else set()
    merged = sorted(existing | slugs)
    path.write_text("\n".join(merged) + ("\n" if merged else ""))
    return merged, len(merged) - len(existing)


async def harvest(http: Http, seeds_path: Path, months: Optional[int] = None) -> dict:
    threads = await list_threads(http, months)
    results = await asyncio.gather(*(harvest_thread(http, h["objectID"]) for h in threads))
    slugs: set[str] = set()
    codes: set[str] = set()
    for s, c in results:
        slugs |= s
        codes |= c
    resolved = await asyncio.gather(*(resolve_short(http, c) for c in sorted(codes)))
    slugs |= {s for s in resolved if s}
    merged, new = merge_seeds(seeds_path, slugs)
    return {
        "threads": len(threads), "slugs": len(slugs), "short_codes": len(codes),
        "new": new, "total": len(merged),
    }
```

```python
"""Greenhouse Job Board API. Thinnest of the three: one free-text location, HTML content."""
from __future__ import annotations

import html
from typing import Optional

from ..http import Http
from ..models import FetchError, Posting
from ..util import strip_tags, to_utc_iso

API = "https://boards-api.greenhouse.io/v1/boards/{slug}/jobs"


def _remote(location: str) -> Optional[bool]:
    low = location.strip().lower()
    if low in ("", "n/a"):
        return None
    return "remote" in low


def parse(slug: str, payload) -> list[Posting]:
    out: list[Posting] = []
    for j in (payload or {}).get("jobs", []):
        loc = ((j.get("location") or {}).get("name") or "").strip()
        content = j.get("content") or ""
        out.append(Posting(
            ats="greenhouse",
            slug=slug,
            job_id=str(j["id"]),
            title=(j.get("title") or "").strip(),
            company=j.get("company_name") or slug,
            location=loc,
            remote=_remote(loc),
            description=strip_tags(html.unescape(content)),  # unescape FIRST
            posted_at=to_utc_iso(j.get("first_published")),
            url=j.get("absolute_url") or "",
            comp=None,
        ))
    return out


async def fetch(http: Http, slug: str) -> list[Posting]:
    status, data = await http.get_json(API.format(slug=slug) + "?content=true")
    if status != 200 or data is None:
        raise FetchError(f"greenhouse:{slug} HTTP {status}")
    return parse(slug, data)


async def count(http: Http, slug: str) -> tuple[int, str]:
    try:
        status, data = await http.get_json(API.format(slug=slug))
    except Exception:
        return 0, slug
    if status != 200 or not data:
        return 0, slug
    jobs = data.get("jobs") or []
    name = (jobs[0].get("company_name") if jobs else None) or slug
    return len(jobs), name
```

```python
"""Lever Postings API. Bare array, `text` is the title, requirements live in lists[]."""
from __future__ import annotations

from typing import Any

from ..http import Http
from ..models import FetchError, Posting
from ..util import strip_tags, to_utc_iso

HOSTS = ["https://api.lever.co", "https://api.eu.lever.co"]
PAGE = 100


def parse(slug: str, payload) -> list[Posting]:
    out: list[Posting] = []
    for j in payload or []:
        cats = j.get("categories") or {}
        locs: list[str] = []
        for loc in [cats.get("location")] + list(cats.get("allLocations") or []):
            if loc and loc not in locs:
                locs.append(loc)
        parts = [j.get("descriptionPlain") or strip_tags(j.get("description") or "")]
        for lst in j.get("lists") or []:
            parts.append(f"{lst.get('text', '')}\n{strip_tags(lst.get('content') or '')}")
        wt = (j.get("workplaceType") or "").lower()
        remote = None if not wt else wt == "remote"
        out.append(Posting(
            ats="lever",
            slug=slug,
            job_id=str(j["id"]),
            title=(j.get("text") or "").strip(),
            company=slug,
            location=" / ".join(locs),
            remote=remote,
            description="\n".join(parts),
            posted_at=to_utc_iso(j.get("createdAt")),
            url=j.get("hostedUrl") or "",
            comp=None,
        ))
    return out


async def _page(http: Http, host: str, slug: str, skip: int) -> tuple[int, Any]:
    return await http.get_json(f"{host}/v0/postings/{slug}?mode=json&skip={skip}&limit={PAGE}")


async def fetch(http: Http, slug: str) -> list[Posting]:
    for host in HOSTS:
        status, data = await _page(http, host, slug, 0)
        if status == 404:
            continue
        if status != 200 or not isinstance(data, list):
            raise FetchError(f"lever:{slug} HTTP {status}")
        items = list(data)
        skip = PAGE
        while len(data) == PAGE:
            status, data = await _page(http, host, slug, skip)
            if status != 200 or not isinstance(data, list):
                break
            items.extend(data)
            skip += PAGE
        return parse(slug, items)
    raise FetchError(f"lever:{slug} 404 both hosts")


async def count(http: Http, slug: str) -> tuple[int, str]:
    for host in HOSTS:
        try:
            status, data = await _page(http, host, slug, 0)
        except Exception:
            return 0, slug
        if status == 200 and isinstance(data, list):
            return len(data), slug
    return 0, slug
```

```python
from __future__ import annotations

import sqlite3
from datetime import datetime, timedelta
from pathlib import Path
from typing import Optional, Union

from .models import Posting

SCHEMA = """
create table if not exists seen (
  key          text primary key,
  first_seen   text not null,
  posted_at    text,
  title        text,
  company      text,
  status       text not null,   -- baseline | stale | dropped | scored | unscored
  reason       text,
  location     text,
  url          text,
  score        integer,
  level        text,
  new_grad_fit real,
  years_stated integer
);
create index if not exists seen_first_seen on seen(first_seen);
create table if not exists dead (
  slug       text primary key,
  checked_at text not null
);
create table if not exists runs (
  started_at  text not null,
  slot        text not null,
  fetched     integer, new integer, stale integer,
  prefiltered integer, scored integer, shown integer
);
create table if not exists meta (
  key   text primary key,
  value text
);
"""

FIELDS = ("location", "url", "score", "level", "new_grad_fit", "years_stated", "status", "reason")


def _iso(dt: datetime) -> str:
    return dt.replace(microsecond=0).isoformat()


class Store:
    def __init__(self, path: Union[str, Path]):
        self.path = Path(path)
        self.con = sqlite3.connect(str(self.path))
        self.con.row_factory = sqlite3.Row
        self.con.executescript(SCHEMA)
        self.con.commit()

    def close(self) -> None:
        self.con.close()

    # --- seen ---
    def is_empty(self) -> bool:
        return self.con.execute("select count(*) from seen").fetchone()[0] == 0

    def has(self, key: str) -> bool:
        return self.con.execute("select 1 from seen where key=?", (key,)).fetchone() is not None

    def get(self, key: str) -> Optional[sqlite3.Row]:
        return self.con.execute("select * from seen where key=?", (key,)).fetchone()

    def insert(self, p: Posting, status: str, reason: Optional[str], first_seen: datetime, **fields) -> None:
        bad = set(fields) - set(FIELDS)
        if bad:
            raise ValueError(f"unknown fields {bad}")
        cols = ["key", "first_seen", "posted_at", "title", "company", "status", "reason"] + list(fields)
        vals = [p.key, _iso(first_seen), p.posted_at, p.title, p.company, status, reason] + list(fields.values())
        self.con.execute(
            f"insert or replace into seen ({','.join(cols)}) values ({','.join('?' * len(cols))})", vals)
        self.con.commit()

    def update(self, key: str, **fields) -> None:
        bad = set(fields) - set(FIELDS)
        if bad:
            raise ValueError(f"unknown fields {bad}")
        sets = ", ".join(f"{k}=?" for k in fields)
        self.con.execute(f"update seen set {sets} where key=?", list(fields.values()) + [key])
        self.con.commit()

    def prune(self, days: int, now: datetime) -> int:
        cutoff = _iso(now - timedelta(days=days))
        cur = self.con.execute("delete from seen where first_seen < ?", (cutoff,))
        self.con.commit()
        return cur.rowcount

    def maybe_vacuum(self, now: datetime) -> bool:
        """VACUUM at most once per calendar month; per-run VACUUM inflates git history."""
        month = now.strftime("%Y-%m")
        row = self.con.execute("select value from meta where key='last_vacuum'").fetchone()
        if row and row[0] == month:
            return False
        self.con.execute("vacuum")
        self.con.execute("insert or replace into meta(key, value) values ('last_vacuum', ?)", (month,))
        self.con.commit()
        return True

    def audit(self) -> list[tuple[str, int]]:
        rows = self.con.execute(
            "select reason, count(*) from seen where status='dropped' group by reason order by 2 desc, 1"
        ).fetchall()
        return [(r[0], r[1]) for r in rows]

    # --- dead slugs ---
    def dead_slugs(self, max_age_days: int, now: datetime) -> set[str]:
        cutoff = _iso(now - timedelta(days=max_age_days))
        return {r[0] for r in self.con.execute("select slug from dead where checked_at >= ?", (cutoff,))}

    def mark_dead(self, slug: str, now: datetime) -> None:
        self.con.execute("insert or replace into dead(slug, checked_at) values (?, ?)", (slug, _iso(now)))
        self.con.commit()

    def unmark_dead(self, slug: str) -> None:
        self.con.execute("delete from dead where slug=?", (slug,))
        self.con.commit()

    # --- runs ---
    def record_run(self, started_at: datetime, slot: str, **counts) -> None:
        self.con.execute(
            "insert into runs(started_at, slot, fetched, new, stale, prefiltered, scored, shown) "
            "values (?,?,?,?,?,?,?,?)",
            (_iso(started_at), slot, counts.get("fetched"), counts.get("new"), counts.get("stale"),
             counts.get("prefiltered"), counts.get("scored"), counts.get("shown")))
        self.con.commit()
```

```python
from __future__ import annotations

import asyncio
import json
from datetime import datetime
from pathlib import Path
from typing import Optional

from .ats import ADAPTERS, PROBE_ORDER
from .http import Http
from .store import Store
from .util import now_utc


async def probe(http: Http, slug: str) -> Optional[dict]:
    """First ATS that returns >=1 posting wins. Empty is a miss: it means wrong ATS, no roles, or upstream error."""
    for ats in PROBE_ORDER:
        n, name = await ADAPTERS[ats].count(http, slug)
        if n > 0:
            return {"slug": slug, "ats": ats, "name": name, "open_roles": n}
    return None


async def verify(http: Http, seeds_path: Path, companies_path: Path, store: Store,
                 dead_days: int = 30, now: Optional[datetime] = None) -> dict:
    now = now or now_utc()
    seeds = [s for s in seeds_path.read_text().split() if s]
    dead = store.dead_slugs(dead_days, now)
    todo = [s for s in seeds if s not in dead]
    results = await asyncio.gather(*(probe(http, s) for s in todo))
    stamp = now.replace(microsecond=0).isoformat()
    companies = []
    for slug, r in zip(todo, results):
        if r:
            companies.append({**r, "verified_at": stamp})
            store.unmark_dead(slug)
        else:
            store.mark_dead(slug, now)
    companies.sort(key=lambda c: c["slug"])
    companies_path.write_text(json.dumps(companies, indent=1) + "\n")
    return {
        "seeds": len(seeds),
        "skipped_dead": len([s for s in seeds if s in dead]),
        "probed": len(todo),
        "confirmed": len(companies),
    }
```

```python
"""Exclusion-only prefilter. Everything that survives goes to the model."""
from __future__ import annotations

import re
from datetime import datetime, timedelta
from typing import Optional

from .models import Posting
from .profile import PROFILE

_YEARS = re.compile(
    r"(\d{1,2})\s*\+?\s*(?:(?:-|–|to)\s*\d{1,2}\s*\+?\s*)?(?:years?|yrs?)\b", re.I)
_EXPERIENCE = re.compile(r"experience|yoe", re.I)
_WINDOW = 40


def _terms_re(terms: list[str]) -> re.Pattern:
    alts = "|".join(re.escape(t) for t in sorted(terms, key=len, reverse=True))
    return re.compile(rf"(?<![a-z0-9])(?:{alts})(?![a-z0-9])", re.I)


def min_years(text: str) -> Optional[int]:
    """Smallest number of years that appears within 40 chars of 'experience' or 'yoe'."""
    best: Optional[int] = None
    for m in _YEARS.finditer(text):
        window = text[max(0, m.start() - _WINDOW): m.end() + _WINDOW]
        if _EXPERIENCE.search(window):
            n = int(m.group(1))
            best = n if best is None else min(best, n)
    return best


def is_stale(posted_at: Optional[str], now: datetime, max_days: int) -> bool:
    if not posted_at:
        return False
    try:
        dt = datetime.fromisoformat(posted_at)
    except ValueError:
        return False
    return dt < now - timedelta(days=max_days)


def _location_ok(p: Posting, profile: dict) -> bool:
    low = p.location.strip().lower()
    if low in ("", "n/a"):
        return True
    if _terms_re(profile["bay_area_terms"]).search(low):
        return True
    non_us = _terms_re(profile["non_us_terms"]).search(low) is not None
    if p.remote is True and not non_us:
        return True
    if p.remote is None and "remote" in low and not non_us:
        return True
    return False


def prefilter(p: Posting, profile: dict = PROFILE) -> Optional[str]:
    if _terms_re(profile["level_terms"]).search(p.title):
        return "level"
    if _terms_re(profile["function_terms"]).search(p.title):
        return "function"
    if not _location_ok(p, profile):
        return "location"
    years = min_years(p.title + "\n" + p.description)
    if years is not None and years > profile["max_years"]:
        return "years"
    return None
```

```python
"""Claude scoring with structured outputs. One call per prefilter survivor."""
from __future__ import annotations

import asyncio
import json
from typing import Any, Optional

import anthropic

from .models import Posting
from .profile import PROFILE

LEVELS = ["new_grad", "junior", "mid", "senior", "unclear"]

SCHEMA = {
    "type": "object",
    "properties": {
        "level": {"type": "string", "enum": LEVELS},
        "new_grad_fit": {"type": "number"},
        "years_stated": {"type": "integer"},
        "score": {"type": "integer"},
        "reason": {"type": "string"},
    },
    "required": ["level", "new_grad_fit", "years_stated", "score", "reason"],
    "additionalProperties": False,
}

SYSTEM_PROMPT = f"""You screen job postings for one specific candidate and return strict JSON.

Candidate: {PROFILE["candidate"]}

Read the whole posting. Titles lie; the body tells you the real level. Decide:

- level: the seniority the posting actually wants. "new_grad" if it explicitly welcomes new grads or 0-1 years. "junior" for 1-2 years or an early-career framing. "mid" when responsibilities or requirements imply 3-5 years even if the title is neutral. "senior" for 5+ years, ownership of teams or systems, mentoring. "unclear" only when the body gives no signal.
- new_grad_fit: 0.0-1.0 probability that this candidate could realistically be hired into this role.
- years_stated: the minimum years of experience the posting states, or -1 if none is stated.
- score: 0-10 for this candidate, calibrated as follows.
  9-10: clearly open to new grads or 0-2 years, a product/founding/FDE/solutions/applied-AI builder role, Bay Area or US-remote.
  6-8: plausible for a strong new grad; level not stated or early-career; minor mismatch on role type or location.
  3-5: reads as mid-level despite a neutral title, or the role type is a stretch (pure research, pure infra, non-engineering).
  0-2: senior in substance, wrong function, or wrong region.
  Penalize implied seniority even when the title sounds junior. Do not reward a role for being at a famous company. Treat "founding engineer" as open unless the body says otherwise.
- reason: at most 15 words, specific to this posting, no fluff.

Return only the JSON object."""


def build_user_message(p: Posting, max_chars: int) -> str:
    desc = p.description
    if len(desc) > max_chars:
        desc = desc[:max_chars] + "\n[truncated]"
    lines = [
        f"Title: {p.title}",
        f"Company: {p.company}",
        f"Location: {p.location or 'unknown'}",
        f"Remote: {p.remote if p.remote is not None else 'unknown'}",
    ]
    if p.comp:
        lines.append(f"Compensation: {p.comp}")
    lines.append("")
    lines.append(desc)
    return "\n".join(lines)


def validate(data: Any) -> dict:
    if not isinstance(data, dict):
        raise ValueError("not an object")
    for k in ("level", "new_grad_fit", "years_stated", "score", "reason"):
        if k not in data:
            raise ValueError(f"missing {k}")
    level = data["level"] if data["level"] in LEVELS else "unclear"
    fit = max(0.0, min(1.0, float(data["new_grad_fit"])))
    years = int(data["years_stated"])
    score = max(0, min(10, int(data["score"])))
    return {
        "level": level,
        "new_grad_fit": fit,
        "years_stated": None if years < 0 else years,
        "score": score,
        "reason": str(data["reason"]).strip()[:200],
    }


async def score_posting(client, p: Posting, profile: dict = PROFILE) -> Optional[dict]:
    """Two attempts. Returns None on repeated failure; the caller surfaces the posting as unscored."""
    for attempt in range(2):
        try:
            resp = await client.messages.create(
                model=profile["model"],
                max_tokens=300,
                system=[{"type": "text", "text": SYSTEM_PROMPT, "cache_control": {"type": "ephemeral"}}],
                messages=[{"role": "user", "content": build_user_message(p, profile["max_description_chars"])}],
                output_config={"format": {"type": "json_schema", "schema": SCHEMA}},
            )
            text = next(b.text for b in resp.content if getattr(b, "type", "") == "text")
            return validate(json.loads(text))
        except (json.JSONDecodeError, StopIteration, ValueError, TypeError, KeyError):
            pass
        except anthropic.APIStatusError as e:
            if e.status_code < 500 and e.status_code != 429:
                return None          # bad request or auth: retrying won't help
        except anthropic.APIConnectionError:
            pass
        if attempt == 0:
            await asyncio.sleep(1)
    return None


async def score_all(client, postings: list[Posting], profile: dict = PROFILE) -> dict[str, Optional[dict]]:
    sem = asyncio.Semaphore(profile["score_concurrency"])

    async def one(p: Posting):
        async with sem:
            return p.key, await score_posting(client, p, profile)

    return dict(await asyncio.gather(*(one(p) for p in postings)))
```

```python
from __future__ import annotations

from datetime import datetime
from typing import Optional

from .util import now_utc


def hours_ago(posted_at: Optional[str], now: datetime) -> str:
    if not posted_at:
        return ""
    try:
        dt = datetime.fromisoformat(posted_at)
    except ValueError:
        return ""
    hours = int((now - dt).total_seconds() // 3600)
    if hours < 0:
        hours = 0
    if hours < 48:
        return f"{hours}h ago"
    return f"{hours // 24}d ago"


def render(date_str: str, slot: str, funnel: dict, shown: list[dict], unscored: list[dict],
           errors: list[str], now: Optional[datetime] = None) -> str:
    now = now or now_utc()
    lines = [f"# jobwatch {date_str} {slot}", ""]
    lines.append(
        f"fetched {funnel['fetched']} · new {funnel['new']} · stale {funnel['stale']} · "
        f"prefiltered {funnel['prefiltered']} · scored {funnel['scored']} · shown {funnel['shown']}"
    )
    lines.append("")
    if not shown:
        lines.append("No new postings worth showing.")
    for e in shown:
        meta = [e["company"], e.get("location") or "location unknown"]
        age = hours_ago(e.get("posted_at"), now)
        if age:
            meta.append(age)
        if e.get("comp"):
            meta.append(e["comp"])
        lines.append(f"- **{e['score']}** [{e['title']}]({e['url']}) — {' · '.join(meta)}")
        if e.get("reason"):
            lines.append(f"  {e['reason']}")
    if unscored:
        lines += ["", f"## Unscored ({len(unscored)})"]
        lines += [f"- [{u['title']}]({u['url']}) — {u['company']}" for u in unscored]
    if errors:
        lines += ["", f"## Fetch errors ({len(errors)})"]
        lines += [f"- {err}" for err in errors]
    return "\n".join(lines) + "\n"
```

```python
"""The daily pipeline: fetch → diff → stale → prefilter → score → digest → prune."""
from __future__ import annotations

import asyncio
import json
from dataclasses import dataclass
from datetime import datetime
from pathlib import Path
from typing import Optional
from zoneinfo import ZoneInfo

import httpx

from .ats import ADAPTERS
from .digest import render
from .http import Http
from .models import FetchError, Posting
from .prefilter import is_stale, prefilter
from .profile import PROFILE
from .score import score_all
from .store import Store
from .util import now_utc


@dataclass
class RunResult:
    shown: int
    digest_path: Optional[Path]
    baseline: bool
    funnel: dict


async def fetch_all(http: Http, companies: list[dict]) -> tuple[list[Posting], list[str]]:
    async def one(c: dict):
        try:
            return await ADAPTERS[c["ats"]].fetch(http, c["slug"]), None
        except (FetchError, httpx.TransportError, KeyError, ValueError) as e:
            return [], f"{c['ats']}:{c['slug']} — {e}"

    results = await asyncio.gather(*(one(c) for c in companies))
    postings: list[Posting] = []
    errors: list[str] = []
    seen: set[str] = set()
    for posts, err in results:
        if err:
            errors.append(err)
        for p in posts:
            if p.key not in seen:
                seen.add(p.key)
                postings.append(p)
    return postings, errors


async def run(http: Http, store: Store, client, companies_path: Path, digests_dir: Path,
              slot: str, profile: dict = PROFILE, now: Optional[datetime] = None) -> RunResult:
    now = now or now_utc()
    companies = json.loads(companies_path.read_text())
    postings, errors = await fetch_all(http, companies)
    funnel = {"fetched": len(postings), "new": 0, "stale": 0, "prefiltered": 0, "scored": 0, "shown": 0}

    if store.is_empty():
        for p in postings:
            store.insert(p, "baseline", None, now)
        store.record_run(now, slot, **funnel)
        return RunResult(0, None, True, funnel)

    new = [p for p in postings if not store.has(p.key)]
    funnel["new"] = len(new)

    fresh: list[Posting] = []
    for p in new:
        if is_stale(p.posted_at, now, profile["max_posting_age_days"]):
            store.insert(p, "stale", "stale", now)
            funnel["stale"] += 1
        else:
            fresh.append(p)

    survivors: list[Posting] = []
    for p in fresh:
        reason = prefilter(p, profile)
        if reason:
            store.insert(p, "dropped", reason, now)
            funnel["prefiltered"] += 1
        else:
            survivors.append(p)

    results = await score_all(client, survivors, profile) if survivors else {}
    shown: list[dict] = []
    unscored: list[dict] = []
    for p in survivors:
        r = results.get(p.key)
        if r is None:
            store.insert(p, "unscored", None, now, location=p.location, url=p.url)
            unscored.append({"title": p.title, "url": p.url, "company": p.company})
            continue
        funnel["scored"] += 1
        store.insert(p, "scored", r["reason"], now, location=p.location, url=p.url, score=r["score"],
                     level=r["level"], new_grad_fit=r["new_grad_fit"], years_stated=r["years_stated"])
        if r["score"] >= profile["min_score"]:
            shown.append({"score": r["score"], "title": p.title, "url": p.url, "company": p.company,
                          "location": p.location, "posted_at": p.posted_at, "comp": p.comp,
                          "reason": r["reason"]})
    shown.sort(key=lambda d: d["posted_at"] or "", reverse=True)   # newest first...
    shown.sort(key=lambda d: -d["score"])                             # ...within score desc (stable)
    funnel["shown"] = len(shown)

    local_date = now.astimezone(ZoneInfo(profile["timezone"])).strftime("%Y-%m-%d")
    digests_dir.mkdir(parents=True, exist_ok=True)
    path = digests_dir / f"{local_date}-{slot}.md"
    path.write_text(render(local_date, slot, funnel, shown, unscored, errors, now=now))

    store.prune(profile["prune_days"], now)
    store.maybe_vacuum(now)
    store.record_run(now, slot, **funnel)
    return RunResult(len(shown), path, False, funnel)
```

```python
from __future__ import annotations

import argparse
import asyncio
import json
import os
import sys
from pathlib import Path

from .http import Http
from .profile import PROFILE
from .store import Store


def load_dotenv(path: Path = Path(".env")) -> None:
    if not path.exists():
        return
    for line in path.read_text().splitlines():
        line = line.strip()
        if not line or line.startswith("#") or "=" not in line:
            continue
        k, _, v = line.partition("=")
        os.environ.setdefault(k.strip(), v.strip().strip('"').strip("'"))


def make_http() -> Http:
    return Http(rps=PROFILE["probe_rps_per_host"], workers=PROFILE["workers"], retries=PROFILE["http_retries"])


async def cmd_harvest(args) -> dict:
    from .harvest import harvest
    http = make_http()
    try:
        return await harvest(http, Path(args.seeds), months=args.months)
    finally:
        await http.aclose()


async def cmd_verify(args) -> dict:
    from .verify import verify
    http, store = make_http(), Store(args.db)
    try:
        return await verify(http, Path(args.seeds), Path(args.companies), store, dead_days=PROFILE["dead_slug_days"])
    finally:
        await http.aclose()
        store.close()


async def cmd_run(args) -> dict:
    import anthropic
    from .run import run
    if not Path(args.companies).exists():
        sys.exit(f"{args.companies} not found: run `python -m jobwatch verify` first")
    http, store = make_http(), Store(args.db)
    client = anthropic.AsyncAnthropic()
    try:
        r = await run(http, store, client, Path(args.companies), Path(args.digests), args.slot)
    finally:
        await http.aclose()
        store.close()
    out = {"baseline": r.baseline, "digest": str(r.digest_path) if r.digest_path else None, **r.funnel}
    print(f"SHOWN={r.shown}")
    print(f"DIGEST={r.digest_path or ''}")
    return out


def main(argv=None) -> None:
    load_dotenv()
    ap = argparse.ArgumentParser(prog="jobwatch")
    sub = ap.add_subparsers(dest="cmd", required=True)

    h = sub.add_parser("harvest", help="HN 'Who is hiring' threads → seeds.txt")
    h.add_argument("--months", type=int, default=None, help="newest N threads (default: all)")
    h.add_argument("--seeds", default="seeds.txt")
    h.set_defaults(fn=cmd_harvest)

    v = sub.add_parser("verify", help="seeds.txt → companies.json")
    v.add_argument("--seeds", default="seeds.txt")
    v.add_argument("--companies", default="companies.json")
    v.add_argument("--db", default="jobwatch.db")
    v.set_defaults(fn=cmd_verify)

    r = sub.add_parser("run", help="fetch, diff, score, digest")
    r.add_argument("--slot", choices=["morning", "midday", "evening", "manual"], default="manual")
    r.add_argument("--companies", default="companies.json")
    r.add_argument("--db", default="jobwatch.db")
    r.add_argument("--digests", default="digests")
    r.set_defaults(fn=cmd_run)

    args = ap.parse_args(argv)
    summary = asyncio.run(args.fn(args))
    print(json.dumps(summary))


if __name__ == "__main__":
    main()
```

`.github/workflows/jobwatch.yml`:

```yaml
name: jobwatch

on:
  schedule:
    # GitHub cron is UTC. These are written for Pacific Daylight Time (UTC-7).
    # When DST ends (early November) they fire an hour earlier Pacific time
    # unless you edit them. To change a slot, edit one line here and the
    # matching line in the "slot" step below.
    - cron: "0 14 * * 1-5"   # 07:00 PDT  morning   Mon-Fri
    - cron: "0 19 * * 1-5"   # 12:00 PDT  midday    Mon-Fri
    - cron: "0 0 * * 2-6"    # 17:00 PDT  evening   Mon-Fri (00:00 UTC next day → Tue-Sat)
  workflow_dispatch:
    inputs:
      slot:
        type: choice
        options: [manual, morning, midday, evening]
        default: manual
      verify:
        type: boolean
        default: false
        description: run verify before the digest

# Runs queue behind each other; never overlap, never cancel.
concurrency:
  group: jobwatch
  cancel-in-progress: false

permissions:
  contents: write
  issues: write

jobs:
  digest:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: "3.12"
      - run: pip install -q -e .

      - name: Resolve slot
        id: slot
        run: |
          case "${{ github.event.schedule }}" in
            "0 14 * * 1-5") slot=morning ;;
            "0 19 * * 1-5") slot=midday ;;
            "0 0 * * 2-6")  slot=evening ;;
            *)              slot="${{ inputs.slot || 'manual' }}" ;;
          esac
          echo "slot=$slot" >> "$GITHUB_OUTPUT"
          echo "date=$(TZ=America/Los_Angeles date +%Y-%m-%d)" >> "$GITHUB_OUTPUT"
          if [ "$slot" = morning ] && [ "$(date -u +%u)" = 1 ] || [ "${{ inputs.verify }}" = true ]; then
            echo "verify=true" >> "$GITHUB_OUTPUT"
          else
            echo "verify=false" >> "$GITHUB_OUTPUT"
          fi

      - name: Verify (weekly, Monday morning)
        if: steps.slot.outputs.verify == 'true'
        run: python -m jobwatch verify

      - name: Run digest
        id: run
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
        run: |
          python -m jobwatch run --slot "${{ steps.slot.outputs.slot }}" | tee run.log
          grep '^SHOWN=' run.log >> "$GITHUB_OUTPUT"
          grep '^DIGEST=' run.log >> "$GITHUB_OUTPUT"

      - name: Commit state
        run: |
          git config user.name "jobwatch-bot"
          git config user.email "jobwatch-bot@users.noreply.github.com"
          git add jobwatch.db companies.json digests/ || true
          git commit -m "jobwatch ${{ steps.slot.outputs.date }} ${{ steps.slot.outputs.slot }}" || echo "nothing to commit"
          git pull --rebase
          git push

      - name: Open issue
        if: steps.run.outputs.SHOWN != '0' && steps.run.outputs.DIGEST != ''
        env:
          GH_TOKEN: ${{ github.token }}
        run: |
          gh issue create \
            --title "jobwatch ${{ steps.slot.outputs.date }} ${{ steps.slot.outputs.slot }} (${{ steps.run.outputs.SHOWN }})" \
            --body-file "${{ steps.run.outputs.DIGEST }}"
```
